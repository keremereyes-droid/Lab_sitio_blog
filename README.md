# 📌 Proyecto: Sitio del Blog

Este proyecto forma parte de una simulación de proyecto SCRUM, donde se desarrolla un sitio web con múltiples páginas, estructura organizada y trabajo colaborativo.

---

## 🧩 Tareas del proyecto

### 🟦 Tarea 1: Retomar o crear el repositorio del proyecto
- Retomar el proyecto previo llamado **"El Sitio del Blog"** o crear un nuevo repositorio.
- Buscar el proyecto anterior de la lección:
  **"TIFC2DEV-SDPF6 Simulación de Proyecto SCRUM"** en GitHub.
- Si el equipo crea un nuevo repositorio, recuperar cualquier repositorio previo relacionado.
- Asegurarse de que **GitHub y VS Code estén correctamente conectados**.

---

### 🟦 Tarea 2: Backlog del proyecto
- Completar el **Product Backlog**.
- Agregar tareas adicionales si son necesarias.
- Crear y asignar **tarjetas (cards) e issues** siguiendo una mentalidad SCRUM.
- Las tarjetas deben estar relacionadas con sus tareas y subtareas.
- Todas las tareas deben estar correctamente documentadas.
- Rango de tareas: **Tarea 1 a Tarea 7**.

---

### 🟦 Tarea 3: Menú de navegación funcional
El sitio web debe incluir un menú de navegación visible en todas las páginas:

- Página de **Inicio**
- Página de **Quiénes somos**
- Página de **Contacto**

📌 Requisitos:
- El menú debe estar presente en todas las páginas.
- Debe permanecer visible al desplazarse (sticky o fijo).

---

### 🟦 Tarea 4: Pie de página funcional
Agregar un footer en todas las páginas con:

- Lista de autores del sitio web
- Correo electrónico de contacto (puede ser ficticio)
- Nombre del proyecto

📌 El pie de página debe ser consistente en todo el sitio.

---

### 🟦 Tarea 5: Página de inicio
Crear contenido relacionado con el tema elegido:

- Usar etiquetas HTML:
  - `h1 - h6`
  - `p`
  - `img`
- Incluir imágenes para mejorar la presentación.
- Aplicar estilos CSS para mejorar diseño visual.
- Ejemplo de diseño:
  - Texto en un lado
  - Imágenes en el otro
  - Colores de fondo para mejorar estética

---

### 🟦 Tarea 6: Página "Quiénes somos"
- Describir al equipo de trabajo.
- Explicar el propósito del grupo.
- Justificar la existencia del sitio web.

---

### 🟦 Tarea 7: Página de contacto
- Incluir información de contacto ficticia:
  - Correos electrónicos
  - Números telefónicos
- No usar información personal real.
- Opcional: agregar un formulario de contacto.

---

## 🚀 Notas finales
Este proyecto está enfocado en aplicar metodología SCRUM, trabajo colaborativo y desarrollo web básico con HTML y CSS.
